# KacApp - Nauka Języka Rosyjskiego

KacApp to nowoczesna aplikacja webowa do nauki języka rosyjskiego, stworzona z myślą o urządzeniach mobilnych.

## Funkcje

- **Lekcje tematyczne**: Dom, Restauracja, Rodzina i wiele innych.
- **Dialogi**: Słuchaj autentycznych rozmów (TTS).
- **Nauka słówek**: Prezentacja z obrazkami i powtarzanie do skutku.
- **Gry**: Dopasowywanie par słówek.
- **Gramatyka**: Tabele odmian czasowników i rzeczowników.
- **Ciekawostki**: Wyjaśnienia trudnych i nietypowych zwrotów.
- **Zdania**: Ćwiczenie pisowni całych fraz.

## Technologia

- React 18
- TypeScript
- Vite
- Framer Motion (animacje)
- Lucide React (ikony)
- Web Speech API (wymowa rosyjska)

## Rozwój

```bash
npm install
npm run dev
```

## Deployment

Aplikacja jest gotowa do wdrożenia na **Vercel**. Każdy push do głównej gałęzi repozytorium spowoduje automatyczny deploy.
